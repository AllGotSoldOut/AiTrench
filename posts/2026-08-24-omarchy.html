Omarchy: DHH's Opinionated Arch-Based Linux, Installed in Five Minutes

August 24, 2026

Omarchy is Basecamp's take on what a developer's Linux machine should look like on day one — and with over 30,000 stars roughly a year after the repo appeared, it has clearly hit a nerve. It's an Arch-based distribution built around Hyprland (Wayland tiling), shipped by DHH as a single ISO with strong opinions baked in: full-disk encryption by default, a curated set of terminal tools, Neovim preconfigured, themes that swap your whole desktop look with one command.

The honest framing: this isn't a distro for people who want to choose their own window manager. It's for people who want DHH's setup — the same environment he uses daily — without spending a weekend assembling it from dotfiles.

Why you'd actually use it

  • Escaping macOS or Windows without losing polish. Omarchy ships unified clipboard history, screenshots and screen recording, OCR text extraction, dictation, and a proper top bar. The manual even has a dedicated "Coming From Mac or Windows" chapter because that's the core audience.
  • A dev machine that's ready in minutes. Terminal, Neovim, shell tools, development tooling, browsers, TUIs — all preinstalled and configured to work together. Installation takes under five minutes on most hardware.
  • Gaming out of the box. There's a whole gaming chapter in the manual; the Arch base means current drivers and Proton-friendly packages.
  • AI-agent-friendly configuration. The entire system is controllable through the omarchy CLI — themes, brightness, bluetooth, capture — which is explicitly designed so you can have an AI agent customize your setup alongside you.
  • Fleet and handoff installs. Ctrl+C at the first installer screen defers personal setup until first boot (great for handing a machine to someone else), and unattended installs let the ISO configure itself from a second drive for VMs.

Getting started

  1. Download the ISO from omarchy.org.
  2. Write it to a USB stick with balenaEtcher (Mac/Windows) or caligula (Linux): 
    # Linux example with caligula
caligula write omarchy.iso
  3. Boot off the stick. You must disable Secure Boot and/or TPM in your BIOS first — they're Microsoft schemes that block unsigned Linux installers.
  4. Answer the configuration questions (keyboard layout, user, etc.) and confirm them. Pick either a full-disk install (wipes the drive) or free-space install for dual booting alongside Windows or another OS. Note: dual-booting with Windows requires turning off BitLocker first. Encryption is on by default; Ctrl+C at the disk-format confirmation opts out.
  5. Select your drive and wait. Under a minute on fast machines, ~5 minutes on older hardware.

One gotcha worth repeating: use a wired or 2.4GHz dongle keyboard. Full-disk encryption means no Bluetooth keyboard works at the pre-boot password prompt — same reason Bluetooth keyboards can't reach your BIOS.

Code & config samples

After install, everything runs through the omarchy CLI. A few examples:

# Update the system
omarchy update

# List and apply themes (changes the whole desktop look)
omarchy theme list
omarchy theme set catppuccin

# Screenshots and recording
omarchy capture screenshot region copy
omarchy capture screenrecording --with-microphone-audio

# OCR text out of a screenshot region
omarchy capture text

# Scriptable menu
omarchy menu summon style.theme

Config lives in Lua files under ~/.config/hypr/. For example, remapping Caps Lock away from its xcompose role in ~/.config/hypr/input.lua:

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

Your customizations are managed as dotfiles in a Git branch (omarchy branch), so updates merge cleanly instead of clobbering your changes.

What's new

Development is very active — the default branch (quattro) saw pushes within a day of this writing, and there's no formal GitHub release; the ISO from omarchy.org is the distribution channel. Recent additions visible in the manual include the expanded omarchy CLI (audio tuning controls, capture commands with webcam overlay), reminders, text extraction & dictation, and the "installing for another owner" flow. The Omacom Foundation also launched with $8 million in funding per the site's news page, which suggests this isn't a weekend project that'll vanish.

Troubleshooting

  • Can't type my disk-encryption password. You're using a Bluetooth keyboard — it can't connect before boot. Plug in a USB cable or 2.4GHz dongle keyboard.
  • "I broke my system with an update!" Roll back via system snapshots first. Still broken? Run omarchy-debug and share output in #omarchy-help on Discord, or restore default configs and packages with omarchy-reinstall.
  • Apps look huge on your display. Omarchy assumes a 2x HiDPI display via GDK_SCALE = 2 in ~/.config/hypr/monitors.lua. On a 1x display, change local omarchy_gdk_scale = 2 to 1 and restart affected apps. For Spotify specifically, Ctrl+Minus shrinks the UI.
  • Caps Lock "doesn't work." It's remapped to the xcompose key for emoji/completion shortcuts. Remap xcompose elsewhere via kb_options = "compose:ralt" in input.lua.
  • Wi-Fi, Bluetooth, audio, or trackpad suddenly dead. Before rebooting, restart just that subsystem: Omarchy menu → Update → Hardware has Wi-Fi, Bluetooth, Audio, and Trackpad reloads. That fixes most "it worked five minutes ago" cases.
  • Locked out after too many password attempts. Hit Ctrl+Alt+F2 for a TTY, log in as root, run faillock --reset --user yourusername.

If you've been curious about Linux but bounced off bare Arch installs, Omarchy removes basically every excuse. Just back up your drive first — the full-disk install means exactly that.
