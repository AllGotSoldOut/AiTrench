AI Engineering from Scratch: the 511-Lesson Curriculum That's Taking Over GitHub

August 24, 2026

ai-engineering-from-scratch is a free, open-source AI engineering curriculum by Rohit Ghumare — and it just crossed ~48,000 GitHub stars. The pitch is in the tagline: "Learn it. Build it. Ship it for others." It covers everything from transformers and NLP to agents, MCP, swarm intelligence, reinforcement learning, computer vision, even Rust and TypeScript alongside Python — organized as 511 lessons across 20 phases.

Why is it trending right now? The August release (v2026.08) added three big things: a certification prep program covering all four Claude credentials from the July 2026 exam guides, translations of the course into five additional languages, and a rebuilt navigation layer for all those lessons. Commits landed as recently as August 23 improving site UX and "agent readiness" — more on that below.

Why you'd actually use it

  1. You're a backend dev pivoting into AI work. You don't need another list of paper summaries — you need a path from "I can call an API" to "I built and shipped an agent system." The phase structure gives you exactly that ladder, and every lesson is meant to be built through, not skimmed.
  2. You're prepping for an AI-related certification. The new certifications section turns public exam blueprints into study paths. The first program covers all four Claude credentials (Associate, Developer, Architect Foundations, Architect Professional) with 33 lessons, runnable labs, diagnostics, capstones, and 295 original assessment questions — free.
  3. You learn best by writing the code yourself. Lessons emphasize implementing things from scratch: transformers, retrieval pipelines, agent loops. If you've ever felt like tutorial-watching wasn't sticking, this build-first format fixes that.
  4. You want an AI-native study workflow. Claude Code, Codex, Cursor, or any SKILL.md-compatible agent can teach a route, run labs, quiz you, and track your progress. Your coding assistant becomes your tutor.
  5. English isn't your first language. Landing pages are committed to the repo in Spanish, French, Portuguese, German, Italian, Chinese, Japanese, Korean, Hindi, Arabic, Russian, and Turkish. English remains canonical; lesson pages are machine-translated on a separate branch.

Getting started

No install ceremony beyond git and Python. Here's the fastest path:

  1. Clone the repo: 
    git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
  2. Browse the table of contents to pick your entry phase — start at Phase 1 if you're new to ML, or jump to the agents/MCP phases if you already know deep learning basics. The ROADMAP.md file lays out all 20 phases: 
    cat ROADMAP.md
  3. Create an isolated environment for lesson code so experiments don't pollute your system Python: 
    python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
  4. If you want the agent-tutor flow, install the course as a skill for your coding agent (per official docs): 
    npx skills add rohitg00/ai-engineering-from-scratch
  5. Prefer reading in a browser? The companion site at aiengineeringfromscratch.com mirrors the curriculum with the new navigation, certifications section, and language switcher.

Code & config samples

The curriculum's whole philosophy is "from scratch," so expect lessons that build primitives before reaching for frameworks. A typical transformer lesson walks you through attention from raw NumPy-style tensors before showing you the PyTorch equivalent. For the agent phases, you'll wire up an MCP server yourself — the kind of exercise most tutorials skip. Exact starter snippets live inside each lesson directory in the repo; the README points you to the contents table as the canonical index, so treat that as your source of truth rather than copying setup code secondhand.

Troubleshooting

  1. Lesson code errors with version mismatches. Course material evolves fast; a snippet written against last month's library may break today. Fix: pin the versions shown in each lesson's requirements and read the lesson's changelog notes before debugging your own code.
  2. You cloned the repo but can't find translated lessons. Only landing pages are committed to main. Full lesson translations live on the translations branch (per docs/i18n.md). Fix: git checkout translations or use the website's language switcher.
  3. The skill-based tutoring flow doesn't pick up your progress. Agent-driven learning depends on your tool supporting SKILL.md properly and having write access to its state files. Fix: verify your agent supports SKILL.md, run it from the repo root, and check that it isn't sandboxed away from the workspace directory.
  4. Duplicate MCP routes confuse your agent. This was a real bug fixed on August 23 ("keep one canonical MCP route"). Fix: pull latest main — if you forked, rebase onto upstream so you get the deduplicated route.
  5. Certification prep questions feel off compared to the real exam. These are original assessment questions built from public blueprints, not leaked exams. Fix: use them as practice signals only and cross-check against the official July 2026 exam guides linked in the certifications section.
