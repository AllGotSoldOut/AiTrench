How to Install Open WebUI (Docker + Ollama)

August 18, 2026 · Install · Docker · Local LLM UI

Trending: open-webui/open-webui — self-hosted ChatGPT-style UI for Ollama and OpenAI-compatible APIs. 149k+ GitHub stars.

Official path is Docker. This guide runs the container, persists data, talks to Ollama on the host, pulls a small model, and checks the UI at http://localhost:3000.

What you need

  • Docker installed and running. WebSocket must be allowed on the network path to the container.
  • Optional: Ollama on the host if you want local models (skip if you use the :ollama image that bundles it).
  • NVIDIA GPU (optional): NVIDIA Container Toolkit, then use the :cuda image with --gpus all.

Step-by-step

  1. Install Ollama on the host (recommended split)

    Linux:

    curl -fsSL https://ollama.com/install.sh | sh
ollama --version

    Windows / macOS: install from ollama.com, then confirm in a new terminal:

    ollama --version

    Pull a small model so the UI has something to chat with:

    ollama pull gemma3:4b
ollama list

  2. Pull and run Open WebUI

    Standard image, data volume, port 3000, restart on boot, reach Ollama on the host:

    docker pull ghcr.io/open-webui/open-webui:main

docker run -d \
  -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

    Windows PowerShell (one line):

    docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

    -v open-webui:/app/backend/data keeps chats and users across container recreates. -p 3000:8080 maps host 3000 → container 8080.

  3. Confirm the container is up

    docker ps --filter name=open-webui
docker logs -f open-webui

    Stop following logs with Ctrl+C once you see it listening. Open:

    http://localhost:3000

    Create the first account — that user becomes admin.

  4. Point the UI at Ollama if models are missing

    Default is often http://host.docker.internal:11434. If the model list is empty, set it explicitly:

    docker rm -f open-webui

docker run -d \
  -p 3000:8080 \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

    Linux host-network alternative (UI then on port 8080):

    docker run -d --network=host \
  -e OLLAMA_BASE_URL=http://127.0.0.1:11434 \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:main

    If Ollama only binds localhost and Docker still cannot reach it, set Ollama to listen on all interfaces, then restart:

    # Linux systemd drop-in
sudo systemctl edit ollama.service
# add:
# [Service]
# Environment="OLLAMA_HOST=0.0.0.0"
sudo systemctl restart ollama

  5. Chat with a model

    In the UI, pick gemma3:4b (or whatever you pulled) and send a test prompt. From the host you can also:

    ollama run gemma3:4b "Reply with the word pong only."

  6. Optional: one container with Ollama bundled

    CPU:

    docker run -d -p 3000:8080 \
  -v ollama:/root/.ollama \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:ollama

    NVIDIA GPU:

    docker run -d -p 3000:8080 --gpus all \
  -v ollama:/root/.ollama \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:ollama

    CUDA image without bundled Ollama: ghcr.io/open-webui/open-webui:cuda plus --gpus all.

  7. Persist the secret key (avoid logout on every recreate)

    openssl rand -hex 32

    Pass it on every docker run:

    -e WEBUI_SECRET_KEY="paste-the-hex-here"

    Without this, recreating the container logs everyone out even if the volume is intact.

Update, Compose, uninstall

Manual update (keep the same volume name):

docker rm -f open-webui
docker pull ghcr.io/open-webui/open-webui:main
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -e WEBUI_SECRET_KEY="your-secret-key" \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:main

docker-compose.yml:

services:
  openwebui:
    image: ghcr.io/open-webui/open-webui:main
    ports:
      - "3000:8080"
    extra_hosts:
      - "host.docker.internal:host-gateway"
    environment:
      OLLAMA_BASE_URL: http://host.docker.internal:11434
      WEBUI_SECRET_KEY: your-secret-key
    volumes:
      - open-webui:/app/backend/data
    restart: always
volumes:
  open-webui:
docker compose up -d

Remove (last command deletes all chats):

docker rm -f open-webui
docker rmi ghcr.io/open-webui/open-webui:main
docker volume rm open-webui
