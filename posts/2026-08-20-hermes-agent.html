How to Install Hermes Agent

August 20, 2026 · Install · CLI · Windows / Linux / macOS

Trending: NousResearch/hermes-agent — self-improving AI agent with persistent memory, skills, and a messaging gateway. 233k+ GitHub stars.

Hermes Agent is an open-source agent from Nous Research. This guide installs the CLI (and optionally the desktop app), configures a model provider, and verifies the install with hermes doctor.

What you need

  • Windows 10/11: PowerShell. No admin, no WSL required for the native install.
  • Linux / macOS / WSL2 / Termux: git, curl. On Debian/Ubuntu also xz-utils (sudo apt install curl xz-utils). Desktop app needs build-essential.
  • You do not pre-install Python, Node, ripgrep, or ffmpeg — the installer does that.
  • An LLM provider: Nous Portal (one login for models + tools) or an API key (OpenRouter, Anthropic, OpenAI, etc.).

Step-by-step

  1. Install on Windows (native PowerShell)

    Open PowerShell or Windows Terminal and run:

    iex (irm https://hermes-agent.nousresearch.com/install.ps1)

    No admin rights. Files go under %LOCALAPPDATA%\hermes\. The installer adds hermes to your User PATH. Close the terminal and open a new one when it finishes.

    Optional flags (scriptblock form):

    & ([scriptblock]::Create((irm https://hermes-agent.nousresearch.com/install.ps1))) -SkipSetup -Branch main

  2. Install on Linux, macOS, WSL2, or Termux

    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc   # or: source ~/.zshrc

    Skip browser automation (no Playwright) if you do not need it:

    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash -s -- --skip-browser

    Per-user layout: code at ~/.hermes/hermes-agent/, launcher at ~/.local/bin/hermes, data at ~/.hermes/.

  3. Confirm the binary is on PATH

    Windows (new PowerShell window):

    Get-Command hermes
hermes --version

    Linux / macOS:

    which hermes
hermes --version

    If you get hermes: command not found, reload the shell or add ~/.local/bin (Unix) / %LOCALAPPDATA%\hermes\hermes-agent\bin (Windows) to PATH.

  4. Configure a model provider

    Fastest path — Nous Portal (300+ models + Tool Gateway in one login):

    hermes setup --portal

    Or pick provider and model interactively:

    hermes setup
hermes model

    Settings live in ~/.hermes/config.yaml (or %LOCALAPPDATA%\hermes\config.yaml on native Windows). API keys go in .env, never in config.yaml. Change values with:

    hermes config set KEY VALUE
hermes config get KEY

  5. Health check

    hermes doctor

    Fix anything it flags (missing PATH, unset API key, stale config). Then:

    hermes config check

  6. Run a first command

    hermes chat -q "What is the capital of France?"
hermes

    hermes with no args starts interactive chat. Other surfaces:

    hermes desktop      # native GUI (alias: hermes gui)
hermes dashboard    # web admin + chat
hermes --tui        # terminal UI

  7. Optional: messaging gateway

    Telegram, Discord, Slack, WhatsApp, and others:

    hermes gateway setup

    Put tokens in .env (for example TELEGRAM_BOT_TOKEN), then start the gateway from the wizard.

If something breaks

SymptomFix
hermes: command not foundNew terminal; source ~/.bashrc; check PATH.
API key not sethermes model or hermes setup --portal.
Config looks empty after updatehermes config check then hermes config migrate.
Windows HTTP 400 / “No models provided”config.yaml saved with a UTF-8 BOM. Re-save UTF-8 without BOM via hermes config edit.
ModuleNotFoundError: dotenvYou ran the repo file with system Python. Use the venv launcher on PATH.
