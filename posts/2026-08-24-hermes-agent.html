Hermes Agent: The AI Agent That Learns From Working With You

August 24, 2026

Hermes Agent (GitHub, MIT) is the open-source AI agent from Nous Research, and it has quietly become one of the biggest repos on GitHub — roughly 236k stars. The differentiator isn't raw model access; it's that Hermes is built to get better at your specific work over time. After a complex task it writes itself a skill, improves that skill during later use, nudges itself to persist knowledge into memory, and can search its own past conversations when you ask about something you discussed weeks ago.

The other half of the pitch: it's not tied to your laptop. Run it on a $5 VPS, a GPU cluster, or serverless backends (Modal, Daytona) that hibernate when idle and cost nearly nothing between sessions — then talk to it from Telegram, Discord, Slack, WhatsApp, or Signal while it works in the cloud.

Why you'd actually use it

  • An assistant that remembers being corrected. The agent-curated memory loop means "we always use pnpm, never npm" said once sticks around. Skills are compatible with the agentskills.io open standard, so what it learns isn't locked into one tool.
  • Unattended automations. A built-in cron scheduler delivers results to any connected platform: a daily repo digest to Slack at 8am, nightly backups, weekly dependency audits — all described in natural language, no crontab syntax.
  • One brain, every chat app. A single gateway process bridges Telegram, Discord, Slack, WhatsApp, Signal and the CLI, with voice memo transcription and conversation continuity across platforms. Start a task on your phone, finish it in the terminal.
  • Parallel workstreams. Spawn isolated subagents for concurrent jobs, or have the agent write Python scripts that call its own tools via RPC — collapsing multi-step pipelines into single low-context turns.
  • No provider lock-in. Use Nous Portal, OpenRouter, OpenAI, Anthropic, or your own endpoint; switch with hermes model and nothing else changes.

Getting started

  1. Install. On Linux, macOS, WSL2, or Termux: 
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    On native Windows, run PowerShell: 
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)

    The Windows installer provisions uv, Python 3.11, Node.js, ripgrep, ffmpeg, and a portable MinGit under %LOCALAPPDATA%\hermes — no admin rights, no interference with any system Git you already have.

  2. Reload your shell and start chatting: 
    source ~/.bashrc    # or: source ~/.zshrc
hermes
  3. Pick your model: 
    hermes model

    If you'd rather not collect five API keys for search, image gen, TTS and a cloud browser, hermes setup --portal wires everything through Nous Portal's single subscription instead.

  4. Run the full setup wizard once to configure tools, channels, and workspace in one pass: 
    hermes setup
hermes tools     # toggle which tools are enabled
  5. Connect messaging (optional but it's the fun part): 
    hermes gateway   # starts the Telegram/Discord/Slack/WhatsApp/Signal bridge
  6. Coming from OpenClaw? There's a migration path: 
    hermes claw migrate --dry-run    # preview first
hermes claw migrate              # persona, memories, skills, keys, settings

Code & config samples

Daily-driver commands worth memorizing:

hermes config set <key> <value>   # set individual config values
hermes config get <key>           # read one back
hermes doctor                     # diagnose issues
hermes update                     # update to latest

For contributors, the installer creates a full git checkout at $HERMES_HOME/hermes-agent (usually ~/.hermes/hermes-agent) matching the managed-install layout:

cd "${HERMES_HOME:-$HOME/.hermes}/hermes-agent"
uv pip install -e ".[all,dev]"
scripts/run_tests.sh

Skills are plain markdown files in ~/.hermes/skills/ — write one yourself describing a procedure and the agent loads it whenever the trigger matches. That's also how the agent saves its own learnings after complex tasks.

What's new

The current stable tag is v2026.8.19 (v0.20.5), released August 19, 2026 — a rollup of roughly 323 merged PRs (~746 commits, +111k lines) since the previous tag. Highlights: Bot Mode group-room threads for chat platforms, foldable conversation summaries, PDF/file attachments with drag & drop, a keyless web tier (five-vendor free rotation with ring failover, so fresh installs get web search with zero API keys), and a CLI polish wave — fuzzy /model picker, Ctrl+P command palette, richer /status.

Commits since then show the pace: browser snapshots now truncate-and-store instead of paying for LLM summarization, terminal environments became pluggable via a plugin registry, the TUI/gateway WebSocket reconnect replay was fixed to actually deliver events, and long Signal/cron deliveries are chunked instead of truncated.

Troubleshooting

  • Windows Defender quarantines uv.exe. Almost certainly a false positive on Astral's unsigned Rust binary — ML antivirus engines flag it routinely. The README documents a full verification flow using GitHub attestations (gh attestation verify) plus hash comparison, and recommends whitelisting the folder (%LOCALAPPDATA%\hermes\bin), not the file hash, since uv updates each version.
  • "Skills index is stale or degraded" warning. This is a known tracked issue (#66616, watchdog-generated). It usually resolves after the skills indexer finishes rebuilding; if it persists, hermes doctor will point at the degraded component before you go deleting anything.
  • Shell commands misbehave on Windows. Hermes runs shell commands through its bundled Git Bash. If a command fails oddly, check whether it assumed PowerShell/cmd syntax; if you have your own Git installed, the installer uses that instead of MinGit.
  • Gateway messages arrive duplicated or events lag after a disconnect. Fixed in recent commits ("make WS reconnect replay actually deliver events") — run hermes update rather than debugging your bot token.
  • Dev setup keeps breaking mid-session. If you clone manually, put the venv outside the source tree — a venv inside the checkout can be wiped by a relative-path command the agent runs against its own files, destroying the runtime while it's working.

Full docs live at hermes-agent.nousresearch.com/docs, and the Discord is active if you hit something odd.
